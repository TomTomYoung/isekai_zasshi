# Markdown組版HTMLテスター 初版仕様

作成日：2026-10-15。対象：TomTomYoung/isekai_zasshi。
開始時master：c0f5b46c6f7745c4b50172a61ac42dde88c1448c。

## 目的と保護範囲

Markdownを原稿の正本とし、組版条件をJSONへ外部化する。HTML画面で文章・画像・余白の寸法を実測し、設定を調整してページごとのPNGをダウンロードする。

初版は `layout-tester/index.html` を入口とする独立した試作経路。既存 `tools/article_source.mjs` は「各節に採用画像1点」「先頭h1+h2」等の契約を持つため、その制約を外して既存出力を変えるのではなく、一般的な原稿向けの別パーサー・共通描画器を追加する。既存の記事ビルド、固定HTML、画像採否、編集承認状態を変更しない。202603・202604の原稿・画像・既存出力は上書きしない。

## 入力と操作

1. MDファイルを選択する、原稿を貼り付ける、または同一サイト内の原稿パスを指定する。
2. ローカル画像を追加する。記事フォルダーの一括選択にも対応し、サブディレクトリを含む相対パスを保持する。候補画像の自動採用は行わず、原稿で指定された画像だけを使う。同名画像を推測して取り違えない。
3. 初期設定・記事設定・個別ブロック設定を順に重ね、自動組版する。
4. 紙面またはブロック一覧から対象を選択し、幅、文字サイズ、行高、余白、画像枠高、改ページ前指定を調整する。
5. 設定JSONをダウンロードして再利用する。本文をレイアウト専用の別原稿へ複製しない。
6. 現在ページのPNG、または全ページのPNGをまとめたZIPをダウンロードする。

試用用の短い原稿を同梱する。Node標準HTTPサーバーを `npm run layout:tester` で起動し、loopbackから使う。PNGの生成とファイル選択は利用者のブラウザ内で行い、原稿を外部サービスへ送信しない。通常の静的HTTP配信でも動かす。file://直開き、CodeSwing、vscode.devの実機対応は初版の保証範囲外で、入口に必要な起動方法を記す。

## Markdownの範囲

横組み。h1〜h6、段落、引用、平坦な番号付き／番号なしリスト、水平線、コードフェンス、パイプ表、独立行のMarkdown画像、既存記事形式のfigure（画像1点とキャプション）を対象とする。インラインは太字、強調、コード、リンク、エスケープを対象とする。

任意HTML・スクリプト・埋込iframeは実行しない。未対応の構造や壊れた記法は行番号と理由を表示し、黙って削除しない。画像はPNG/JPEG/WebP等の静止ラスター画像に限定し、外部URL・SVG・動画は初版では受け付けない。欠落画像はエラーとし、PNG出力を止める。

ブロックIDは内容由来の自動IDを基本とし、前方への別段落の挿入で無関係な設定がずれないようにする。同一内容の重複ブロックは識別が曖昧になるため警告する。必要な箇所は直前の `<!-- block:任意のASCII識別子 -->` で固定できる。IDの重複はエラー。本文改稿で自動IDが変わった場合は未適用設定を警告する。

`<!-- pagebreak -->` で明示改ページを指定できる。コメントを原稿へ自動挿入することはない。

## 外部設定

`layout-tester/defaults.json` を共通初期値の正本とする。記事設定を読み込み、その上に `blocks` 内のID別指定を適用する。初期紙面1456×2056 CSS px、外周余白64px、本文28px、行高42px。表示ズームは紙面の座標にもPNG出力倍率にも影響させない。

設定はversion付きJSON。紙面W/H、上下左右padding、段数と段間、本文フォント・サイズ・行高・段落間、見出し、画像枠高・contain/cover・キャプション、個別ブロックの幅・margin・padding・改ページ前指定、出力倍率を保持する。画像の縦横比を変える非均一拡大縮小は禁止。coverは比率を保った裁ち落としとして明示する。

不正な型、未知のキー、非有限値、負寸法、紙面を消す余白、過大な出力は拒否する。設定読込失敗時には現行設定を保持し、旧設定を新設定の成功結果として扱わない。

## 組版・計測

文字を横につぶして収めない。指定幅で折り返し、フォントと画像の読込後にDOMを実測する。ページ・段を順に流し、収まらないブロックを次へ送る。長い段落は文字の結合単位を壊さず、インライン装飾を保って分割する。見出しは次の内容から孤立させない。分割不能な巨大画像・表・見出し等は警告またはエラーを表示し、無断縮小や本文切捨てで合格にしない。

文章寸法は要素箱の寸法であり、黒い文字画素の厳密な面積ではない。選択対象のW/H、紙面基準のx/y、上下左右margin/padding、前後の実間隔、紙面端までの距離をCSS pxで示す。画像は配置枠と、contain/cover適用後の画像矩形・可視範囲を区別する。各ページの外周余白、本文領域、段間、ブロック枠をガイド表示する。

はみ出し・重なり・画像欠落を表示し、未組版の編集内容がある状態やエラー状態ではPNG出力しない。非同期処理中に再編集されても古い結果が最新結果を上書きしないよう世代管理する。設定を変えた際、未対応記法を取り込んだ際も、古い合格表示を残さない。

## 出力

プレビューとPNGで別の組版器を使わない。確定済みの紙面DOMからガイド・選択枠を除去した複製を作り、自己完結したスタイルと画像を使ってSVG foreignObject経由でCanvasへラスタライズする。ブラウザの描画機能を使う限定された実装であり、任意CSSの完全な画面撮影機能とは呼ばない。Chromiumで表示と出力を比較する。

出力倍率1なら1456×2056、倍率2なら2912×4112。画面の50%表示とは独立する。PNG書出し失敗時は空画像を成功扱いしない。全ページZIPはページ順の連番PNGを格納する。OSフォントを使う初版は別環境で同じ改行・画素を保証せず、利用フォント名と検証環境を記録する。

## 検証と初版外

パーサー、設定検証、安定ID、ZIP、長段落の保存性、画像比率、ズーム不変、余白・はみ出し、欠落画像、設定往復、PNGサイズ・ガイド除外、実ダウンロード、ローカルHTTPのパス制限を自動試験する。Playwrightは既存開発依存を利用し、新しい外部CDN依存を導入しない。

自由配置のドラッグ操作、縦書き、任意HTML/CSS、複雑な入れ子Markdown、表の自動分割、完全な禁則・孤立行制御、フォントの同梱固定、既存記事ビルドへの設定統合、校了・全号EPUB生成は初版の完了条件に含めない。実装後の確認結果と残件は本書または `tests/layout-tester/README.md` に追記する。
