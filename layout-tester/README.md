# Markdown組版テスター

更新日：2026-10-15。仕様：[doc/HTML_LAYOUT_TESTER.md](../doc/HTML_LAYOUT_TESTER.md)。

## 起動

Node.js 18以降がある環境で、リポジトリ直下から起動します。テスターの実行にnpm installや外部CDNは不要です。

```sh
npm run layout:tester
```

表示された `http://127.0.0.1:4173/layout-tester/` をブラウザで開きます。ポートが使用中なら `npm run layout:tester -- --port=4174`。停止はターミナルでCtrl+Cです。

Node標準HTTPサーバーは読取専用・loopback限定です。任意の静的HTTPサーバーでも `layout-tester/index.html` を配信できます。file://直開きはES modulesとJSON取得のため対象外です。初版ではCodeSwing / vscode.devの起動経路を変更していません。

## 使い方

最初は試用原稿と寸法確認用の画像を表示します。左の「MDを開く」で原稿を選び、「画像を追加」で参照画像を選びます。原稿と画像がサブフォルダーに分かれている場合は「記事フォルダーを開く」を使います。複数のMDがある場合は、読込対象を選択してください。

「リポジトリ内の原稿を読む」にリポジトリ相対パスを入力すれば、配置済みのMDと、そのMDから相対指定された画像を読み込めます。外部サイトの原稿・画像を自動取得する機能ではありません。

中央の文章・画像をクリックすると、右上にW/H、x/y、margin、padding、前後の間隔、紙面端までの距離を表示します。値は拡大縮小前のCSS pxです。画像は「枠」「比率保持後の矩形」「可視範囲」「元画像」を区別します。

右側の共通設定、または「このブロックの個別調整」を変更すると再組版します。幅は文字の折返し幅であり、横方向の変形倍率ではありません。画像のcontainは全体を収め、coverは縦横比を保って枠外を裁ち落とします。

「設定JSONを保存」で調整値を外部化し、次回の「設定JSONを読み込む」で復元できます。共通初期値の正本は `defaults.json`、個別指定はJSONの `blocks` です。JSON直接編集もできます。原稿をレイアウト専用ファイルへ自動複製せず、既存ファイルへの保存・上書きもしません。

「このページをPNG」で表示中のページを出力します。「全ページZIP」はページ順のPNGをまとめます。ガイドは出力しません。出力倍率1なら1456×2056px、2なら2912×4112pxです。画面の表示倍率とは独立します。

## 初版の範囲

横組み、1〜3段、h1〜h6、段落、引用、平坦な `-` / `+` / 番号付きリスト、コードフェンス、パイプ表、独立行のMarkdown画像、指定構造のfigureに対応します。インラインは `**太字**`、`*強調*`、コード、http(s)等のリンク、バックスラッシュによるエスケープです。underscoreによる強調、入れ子リスト、脚注、任意HTML等には未対応です。未対応記法はエラーにします。

画像はPNG/JPEG/WebP。原稿中の画像だけを使用し、候補を推測しません。同じファイル名でもディレクトリが違えば区別します。画像は読込時にPNGへラスタライズして出力へ内包します。アニメーション画像の再生・保存は対象外です。

固定IDは `<!-- block:lead -->` のように本文ブロックの直前へ手動指定できます。自動IDは内容由来です。無関係な段落の前方挿入ではIDを変えませんが、同一段落の改稿や同文の重複には注意が必要です。未適用設定・重複内容は警告します。明示改ページは `<!-- pagebreak -->`。

長い段落・引用・コードは結合文字を壊さず分割し、原文との一致を確認します。表・リスト・画像等の巨大な分割不能ブロックは出力を停止します。完全な禁則・孤立行制御、自由配置のドラッグ、縦書き、全号生成への統合は未実装です。

既存 `tools/article_source.mjs` の契約や記事ビルドとは独立しています。本テスターを使っても記事の承認・校了・既存PNGの同期完了とは扱いません。

## 読込とテストの安全性

原稿・画像のHTTP取得は同一originに限定し、認証情報を送信せず、リダイレクトも追いません。付属サーバーは読取専用・127.0.0.1待受で、cross-site要求と異なるOriginを拒否します。

ブラウザ試験はサンドボックス有効の通常HTTP経路だけを使います。管理環境が起動や遷移を拒否した場合は、保護設定を変更せず失敗として報告します。
