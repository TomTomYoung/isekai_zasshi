# 21_花見宿ガイド 企画

## 役割

202604号後半の事件簿兼実用ガイド。花見シーズンの宿不足、予約詐欺、二重予約、貴族客優先、地下部屋押し込みを扱い、読者が笑いながらも不安になるページにする。

```text
本文量: 1400〜2200字
想定ページ: 2〜3ページ

```

## 記事の核

王都南区の花見宿で、予約済みの旅客が次々と追い出され、空き部屋は貴族客と高額客に回されていた。

単なる宿不足ではなく、祭り前後にだけ現れる臨時仲介人、酒場経由の口約束、地下倉庫を客室と言い張る宿側の商売をまとめて暴く。

## 構成案

```text
1. 花見の夜、宿を失った旅人たち
2. 二重予約はどう作られるか
3. 地下部屋・馬小屋・物置を客室化する宿
4. 貴族客優先と口止め酒
5. 南区宿選び危険度表
6. 本誌の見立て
```
