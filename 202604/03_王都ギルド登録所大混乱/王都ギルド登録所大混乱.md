# 王都ギルド登録所大混乱
## 朝五時から並んで、登録証は夕方――番号札四十七番の長い一日

午前五時二十分、王都中央ギルドの石段には、まだ誰も座っていなかった。

「一番だ」

樫枝村から来たネリクは荷袋を下ろした。背負ってきた槍を壁に立てかけ、母親の包んだ黒パンを半分食べた。残り半分を出しかけたところで、横手の路地から男が顔を出した。

「登録なら、列はこっちだよ」

石段は依頼人用の正面入口。登録希望者は西側の通用門から入る。ネリクの前には、すでに四十六人いた。

## 七時四十分　木札には、まだ何の身分もない

臨時受付係が配った木札には、大きく四十七と彫られていた。ネリクはそれを首から下げた。すぐ前の青年も、同じように下げている。

「それは返してもらいます。冒険者札ではありません」

受付係のエダが声を張る。列から七、八人がいっせいに首の紐を外した。

この日の配布上限は二百四十枚。ただし木札で確保できるのは、最初の書類確認の順番だけだった。適性確認と登録札交付には、それぞれ別の待ち順がある。掲示板の案内には三段階とも書かれていたが、前に立つ希望者の荷袋と大盾で、下半分が見えなかった。

エダは案内を一枚はがし、掲示板の上端へ貼り直した。今度は小柄な希望者が読めない。

「読める人、後ろへ伝えてください！」

王都最初の共同作業は、列の中で始まった。

## 九時十分　推薦状は四枚、身元の裏付けは一つ足りない

ネリクが持参したのは、村の鍛冶屋、教会、街道宿、幼なじみの父親が書いた推薦状。四人とも「丈夫で正直」と太鼓判を押していた。ところが、生年月日を書いた人は一人もいない。

「お父さんの友達は、あなたを何年見ていますか」

「生まれた時からです」

「それを紙に書いてほしかったんです」

エダは四枚を突き返さず、教会の紹介文にある司祭名を照会簿で探した。登録に推薦状が四枚必要なわけではない。ネリクが村で相談するたび、親切な大人が一枚ずつ増やしてくれたのだ。

一方、隣の窓口では立派な家紋入り封筒が止まっていた。封筒には家名しかなく、中の紹介状は白紙だったという。

昼前、職員が入口に新しい紙を貼った。

> 本日のお願い：封筒の中を一度見てから並んでください。

## 正午　最初の試験は「帰ると言えるか」

身元照会を終えたネリクは、適性確認の待機室へ回った。机に置かれていたのは剣ではなく、依頼票と地図と十二枚の木片だった。

依頼票を読めるか。報酬を三人で分けられるか。日没までに戻れる道はどれか。ここで読み書きに詰まった希望者は、その場で登録不可になるのではなく、補助説明の席へ移される。

ネリクが困ったのは、撤退判断の問いだった。

「仲間が足を傷めました。目的地はもうすぐです。どうしますか」

「俺が背負って、最後まで行きます」

試験係のドルンは、地図の帰り道を指でなぞった。

「帰りも背負うんだぞ」

ネリクはしばらく黙り、「帰ります」と答え直した。勇ましい答えを求められていると思っていたらしい。

待機室では、鞘を買っていない青年が剣を布で巻き直していた。別の青年は申込書の得意分野に書いた「何でも」を消し、「荷運び」と書いた。外の掲示板では、高額討伐の依頼札が風に鳴っている。

## 四十七番が通った三つの列

| 時刻 | 場所・手続き | ネリクの手元にあるもの |
|---|---|---|
| 05:20 | 正面入口へ到着。登録列へ移動 | 槍、荷袋、推薦状四枚 |
| 07:40 | 入場順の木札を受領 | 四十七番札 |
| 09:10 | 書類確認。身元照会待ちへ | 確認中の紙片 |
| 12:00 | 適性確認室へ | 試験用の地図と木片 |
| 14:25 | 登録内容の記入・交付待ち | 名前の読みを確認する控え |
| 16:10 | 登録札交付 | 本人名入りの鉄札 |

朝の順番が交付まで引き継がれる仕組みではない。百番台の希望者が先に鉄札を受け取り、四十七番がまだ椅子に座っている。追い越されたと怒る声が上がるたび、エダは書類照会と試験の順番を説明し直した。

## 十七時半　登録札百八十六枚、翌日持ち越し五十四人

窓口が閉まった時点で、当日分二百四十人のうち交付完了は百八十六人。書類の差し戻しが四十一人、照会・適性確認の持ち越しが十三人だった。持ち越しの希望者には、どこから再開するかを書いた控えが渡された。

「明日も最初から並ぶんですか」と尋ねられ、エダが控えの印を指す。列を抜けた男が安堵した顔で宿屋の方向へ走った。夕方の客引きは、その控えを目印に声をかけていた。

窓口の内側には返却された番号札が積まれていた。紐が絡んだもの、汁の染みたもの、角に小さな星を彫られたもの。四十七番には、首から下げるために結んだ紐がまだ残っていた。

広場でネリクを見つけた。鉄札を服の上へ出したり、中へしまったりしている。

初仕事は何をするつもりかと聞くと、朝から背負ってきた槍ではなく、ギルドの戸口を見た。

「明日の列の案内、人を募集してました」
