# 02_王都ギルド登録所大混乱 企画

## 目標

春の王都に人が集まることで、ギルド登録所が混み合う様子を描く。

```text
本文量: 1800〜2400字
想定ページ: 2ページ前後
入れる要素: 時刻別表、列の描写、受付側コメント
```

## 構成

```text
1. 夜明け前から並ぶ登録希望者
2. 書類確認と適性試験
3. 待ち時間で増える不安
4. 受付側の説明
5. 本誌の見立て
```

## 表案

```text
時刻 / 場所 / 混み具合 / 本誌コメント
早朝 / 正門前 / 高い / 番号札待ち
午前 / 受付前 / 高い / 書類確認
昼 / 試験室前 / 中程度 / 待機時間長め
夕方 / 掲示板前 / 高い / 翌日案内
```

## 画像案

ギルド登録所の前に並ぶ新人冒険者、掲示板、番号札、受付窓口。
