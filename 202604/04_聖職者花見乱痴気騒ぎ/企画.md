# 03_聖職者花見乱痴気騒ぎ 企画

## 目標

春祭りの花見会場で起きた聖職者たちの騒ぎを、俗っぽい目撃記事として厚くする。

```text
本文量: 1800〜2400字
想定ページ: 2ページ前後
入れる要素: 目撃証言、時系列、屋台主コメント、教会側コメント
```

## 構成

```text
1. 清めの酒がただの酒に変わるまで
2. 説法と屋台値切りの境界線
3. 花見客が見た一部始終
4. 教会側の説明
5. 本誌の見立て
```

## 追加する表

```text
時刻 / 出来事 / 周囲の反応 / 本誌コメント
昼 / 祝福の挨拶 / 穏やか / まだ式典の空気
夕方 / 酒席化 / 見物客増加 / 境界が曖昧になる
夜 / 屋台前で口論 / 騒がしい / 花見客の注目を集める
翌朝 / 片付け / 苦情あり / 祭り後の現実
```

## 証言案

```text
「説法を聞いていたはずが、途中から屋台の値段に説教していた」
「ありがたい話だったが、最後は会計の話になっていた」
```

## 画像案

花見会場、屋台、聖職者の一団、見物する町人。明るい春の風景だが、誌面は俗っぽく煽る。
