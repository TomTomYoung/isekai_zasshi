# 20_魔術学院入学式失踪事件 企画

## 役割

202604号後半の事件簿。春の入学シーズンを、魔術学院という格式ある舞台に接続し、浮かれた新生活記事から一段暗い事件記事へ移行させる役割。

## 目標ボリューム

```text
本文量: 1600〜2400字
想定ページ: 2〜3ページ
必須要素: 時系列、学院関係者証言、召喚陣図解風リスト、禁書庫・寮・裏口入学の噂
```

## 記事の核

王都魔術学院の入学式当日、新入生のひとりが式典会場から忽然と消える。

事故なのか、召喚魔術の暴走なのか、学院内部のいじめなのか、裏口入学をめぐる口封じなのかを、本誌らしく疑惑過多で煽る。

## 構成案

```text
1. 晴れの日に消えた新入生
2. 式典会場に残された未完成の召喚陣
3. 寮で囁かれる「先輩歓迎儀式」の噂
4. 禁書庫裏口と裏口入学リスト
5. 学院側の説明と保護者の怒号
6. 本誌の見立て
```

## 追加する表

```text
時刻 / 出来事 / 学院発表 / 本誌注目点

09:00 / 入学式開始 / 問題なし / 座席表に空白あり
09:35 / 魔力測定 / 軽微な乱れ / 召喚陣反応の可能性
10:20 / 本人不在判明 / 体調不良扱い / 医務室に記録なし
```

## 証言案

```text
「式の途中で、床の紋様が一瞬だけ光ったんです」
「学院は“迷子”と言っていますが、あの建物で新入生がひとりで禁書庫へ行けるわけがありません」
「裏口入学の名簿を見た、という先輩が急に黙りました」
```

## 画像・図版案

```text
大講堂の床に残る薄い召喚陣、式典用ローブの新入生たち、青ざめる教師、遠くに閉ざされた禁書庫の扉。
```

## 増補ポイント

- 学院の格式と隠蔽体質を強調する。
- 召喚陣を「図解風」にして雑誌らしい見せ場を作る。
- 真相は断定しすぎず、複数疑惑を並べて事件簿感を出す。
