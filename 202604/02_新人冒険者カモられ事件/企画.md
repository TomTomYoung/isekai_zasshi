# 01_新人冒険者カモられ事件 企画

## 役割

202604号の巻頭スクープ。3月号の巻頭記事と同じく、号全体の俗っぽさと密度を決める最重要記事。

## 目標ボリューム

```text
本文量: 2500〜3200字
想定ページ: 2〜4ページ
必須要素: 証言、相場表、チェックリスト、現場描写
```

## 記事の核

春の王都へ出てきた新人冒険者が、登録前から装備屋、案内人、宿屋、地図売り、依頼紹介人に次々と金を取られる。

単なるぼったくりではなく、王都に不慣れな新人の不安、恥、見栄につけ込む春の恒例商売として描く。

## 構成案

```text
1. 王都の春は初心者狩りの季節
2. ギルド前に立つ親切な案内人
3. 革鎧、薬草、地図、登録代行料の罠
4. 新人が払った初日費用一覧
5. 本当に必要だったものは何か
6. 本誌の見立て
```

## 追加する表

```text
商品 / 請求額 / 適正相場 / 本誌コメント
革鎧一式 / 高額 / 中程度 / 初日に買う必要は薄い
薬草束 / 高額 / 低額 / ギルド内で買える
王都地図 / 高額 / 無料配布あり / 古い地図の可能性
登録代行 / 高額 / 不要 / 本人申請で足りる
```

## 証言案

```text
「今思えば、全部いらなかった。ギルドの中で聞けば済む話だった」
「強そうに見られたくて、断れなかった」
「案内人だと思っていたら、店の客引きだった」
```

## 画像・図版案

```text
王都ギルド前、荷物を抱えた新人冒険者、笑顔で声をかける案内人、後ろに装備屋と宿屋の看板。
```

## 増補ポイント

- 新人の心理を厚くする。
- 金額表を必ず入れる。
- 最後は「希望の入口には値札が貼られている」という皮肉で締める。
