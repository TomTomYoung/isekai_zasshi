# 02_ギャルギルド 企画

## 役割

202604号の春向け冒険特集。冒険者文化を仕事や死闘ではなく、学生の流行と遊びの側から紹介する記事。

## 記事の核

王都西街区で学生たちが始めた、非公式かつゆるい冒険文化「ギャルギルド」を紹介する。

正式な冒険者ギルドではなく、学園御三家の学生も多数参加するグループ群。安全な低級ダンジョンへ出かけ、記念写真魔法プリウラを撮り、拾ったアイテムで装備をデコる。

本格的な攻略を目的としないため、冒険素人も受け入れてもらいやすい。

## 必須の冒頭

```text
春だ。冒険の季節だ。
王都も冒険一色である。
素人冒険者におすすめなのは、ギャルギルドである。
```

## 構成

```text
1. 春だ、冒険の季節だ
2. 王都も冒険一色
3. 冒険素人におすすめなのがギャルギルド
4. ギャルギルドとは
5. 王都西街区から始まった流行
6. 学園御三家からも相当数が参加
7. アムロミレイの影響
8. 低級ダンジョンをゆるく探索
9. プリウラ撮影と拾得品デコ
10. 素人が受け入れられやすい理由
11. 仕事のギルドではなく遊びのギルド
```

## 固有設定

- 流行の中心地：王都西街区
- 流行を決定づけた冒険者：アムロミレイ
- 記念写真魔法：プリウラ
- 参加者：学生主体
- 学園御三家：王都桜花学園、金獅子女学院、薔薇十字女学院
- 組織形態：本部や統一規則を持たない非公式グループ群

## 画像・図版案

```text
王都西街区の広場に集まる学生冒険者たち。改造制服とデコった軽装備。低級ダンジョン踏破後、魔法写真プリウラを囲んで盛り上がる。鞄や杖には拾った魔石、牙、金具が飾られている。
```

## 文体

- 雑誌の流行紹介記事。
- 深刻にしすぎない。
- ギャルを単なる口調や服装ではなく、学生同士の模倣、装備改造、口コミ、横のつながりから生まれた文化として描く。
- 最後は「初めての冒険は、そのくらい軽くていい」で締める。
