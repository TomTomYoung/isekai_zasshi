# 22_新人冒険者パーティー流星猫事件 企画

## 役割

202604号後半の人物事件簿。春に結成された新人冒険者パーティーの見栄、炎上、借金、名声欲を扱い、巻頭の新人カモられ記事と呼応させる。

## 目標ボリューム

```text
本文量: 1600〜2400字
想定ページ: 2〜3ページ
必須要素: メンバー表、借金内訳、炎上経緯、ギルド関係者証言
```

## 記事の核

新人冒険者パーティー「流星猫」は、派手な名前と宣伝で注目を集めたが、実力不足のまま高難度依頼に手を出し、装備ローン、宿代未払い、虚偽戦果報告で炎上する。

悪人というより、王都の春に浮かされた新人たちが、名声と借金で自滅していく事件として描く。

## 構成案

```text
1. 王都に現れた期待の新人パーティー
2. 名前だけ先に売れた「流星猫」
3. 初回依頼失敗と虚偽戦果報告
4. 装備ローン、宿代、治療費の雪だるま
5. ギルド掲示板炎上の一部始終
6. 本誌の見立て
```
