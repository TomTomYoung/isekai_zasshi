# 王都通信公社

王都通信公社は、王都内外の通信網、街道通信塔、監視塔、非常警報網、ダンジョン周辺通信、ダンジョン内通信試験を扱う半官半民の通信組織である。

文官府、魔術師協会、商会、軍務院が関与するため、純粋な公共機関ではなく、インフラ利権の中心でもある。

```text
王都通信公社
├─ 術式通信網管理局
├─ 街道通信塔管理局
├─ 監視塔連絡局
├─ ダンジョン周辺通信局
├─ ダンジョン内通信試験局
└─ 非常警報網管理局
```

#### 主な権限

- 王都内通信網の維持
- 街道通信塔の管理
- 交易路警報の発信
- ダンジョン周辺の臨時通信拠点設置
- ダンジョン内通信試験
- 魔物災害・ダンジョン災害の非常警報
- 通信優先順位の設定
