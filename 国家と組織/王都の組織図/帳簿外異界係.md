# 帳簿外異界係

帳簿外異界係は、王都の公的組織図には存在しない秘密連絡機関である。

正式な庁でも局でもない。  
文官府、武官府、聖教会、魔術師協会、王都静謐会議、王都通信公社の一部関係者が、異世界転生者・異世界漂着者・異界由来物品・異界知識流入事案を扱うために作った非公開の横断組織である。

「帳簿外」とは、財務帳簿に載らないという意味だけではない。  
戸籍、裁判記録、学院記録、商会帳簿、通信記録、施療記録のどこにも正規の項目として載せられない事案を扱う、という意味である。

```text
帳簿外異界係
├─ 異界人物仮記録係
├─ 異界知識評価係
├─ 異界物品封匿係
├─ 保護・監視調整係
├─ 記録改竄・秘匿係
├─ 社会影響評価係
├─ 黒槍別働隊連絡係
├─ 禁式監察室連絡係
└─ 異魂審問室連絡係
```

## 位置づけ

表向きには存在しない。

書類上は、王都静謐会議の臨時連絡会、魔術行政院の未分類事案記録、聖教会の魂魄異常審問、王都通信公社の通信異常調査、武官府の特殊任務記録などに分散して処理される。

そのため、帳簿外異界係に直接の庁舎はなく、会議場所も固定されない。

## 主な対象

- 異世界転生者
- 異世界漂着者
- 召喚事故で現れた人物
- 前世記憶保持者
- 異界由来の知識を持つ人物
- 異界由来の物品・書籍・機械
- 既存魔術体系では説明できない技術
- 王都社会に大きな影響を与える可能性がある思想・制度・技術

## 主な役割

- 異界由来人物の保護または監視
- 異界知識の危険度評価
- 異界物品の保管・鑑定
- 王都社会への影響評価
- 貴族・商会・魔術師協会への情報流出防止
- 異界由来技術の利用可否判断
- 王都静謐会議への秘匿報告
- 必要時の黒槍別働隊投入調整

## 主な権限

公式には権限を持たない。

ただし実務上は、関係機関の権限を束ねて動く。

```text
実務上使われる権限
├─ 文官府の記録封印
├─ 武官府の限定封鎖
├─ 魔術師協会の術式鑑定
├─ 聖教会の魂魄審問
├─ 王都通信公社の通信記録照会
├─ 灰梟局の身辺調査
└─ 黒槍別働隊の限定出動
```

## 処理方針

異世界転生者や異世界漂着者は、原則として以下のいずれかに分類される。

```text
異界人物分類
├─ 保護対象
│  ├─ 生活能力が低い
│  ├─ 政治的利用価値が高すぎる
│  ├─ 本人に敵意がない
│  └─ 王都社会への影響が限定的
│
├─ 観察対象
│  ├─ 異界知識を持つ
│  ├─ 商会・貴族・学院と接触している
│  ├─ 魔術体系に影響を与えうる
│  └─ 本人の思想や目的が不明
│
├─ 協力対象
│  ├─ 王国に有益な技術・知識を持つ
│  ├─ 本人が協力的
│  ├─ 管理可能な生活基盤がある
│  └─ 情報統制が可能
│
├─ 隔離対象
│  ├─ 王都秩序に重大な影響を与える
│  ├─ 危険な異界知識を流布している
│  ├─ 魔術的異常を伴う
│  └─ 外部勢力に利用されている
│
└─ 抹消対象
   ├─ 公式記録から存在を消す必要がある
   ├─ 本人を消す意味ではなく、記録・噂・流通経路を断つ
   ├─ 秘匿保護へ移す場合もある
   └─ 王都静謐会議の承認が必要
```

## 注意点

帳簿外異界係は、異世界転生者を一律に敵視しない。

むしろ王都側にとって最も恐ろしいのは、本人の戦闘力ではなく、異界由来の知識が王都の制度、産業、金融、軍事、魔術、宗教観を急速に変えてしまうことである。

そのため、この係の本質は「討伐」ではなく、保護、監視、秘匿、評価、利用制限である。
