# 王都の組織図

## 概要

王都の統治機構は、国王を頂点としつつ、王族会議、貴族院、枢密院、宮廷府、文官府、武官府、聖教会、魔術師協会が相互に牽制しながら動いている。

王都は単なる都市ではなく、王宮、中央官庁、軍務機構、貴族家、商会、教会、魔術師協会が集中する政治都市である。そのため、行政、軍事、儀礼、財政、魔術、信仰、貴族利害が複雑に重なっている。

```text
国王
├─ 王族会議
├─ 貴族院
├─ 枢密院
├─ 宮廷府
├─ 文官府
├─ 武官府
├─ 聖教会
└─ 魔術師協会
```

## 最上位機関

### 国王

王国統治の最終権限者。

勅令、叙爵、軍の統帥、主要人事、外交承認、恩赦、非常時命令などの最終決定権を持つ。ただし実務の多くは宮廷府、文官府、武官府、枢密院、貴族院を通して処理される。

#### 主な権限

- 勅令の発布
- 高官任命
- 爵位授与
- 軍事動員の承認
- 外交条約の承認
- 王都非常事態宣言

### 王族会議

王族内部の利害調整機関。

王位継承、王族婚姻、王族領、王族の公務分担、王宮内の序列を扱う。政治決定機関というより、王家内部の合意形成と火種の処理を担う。

#### 主な権限

- 王族婚姻の事前審議
- 王位継承順位に関する確認
- 王族領の管理方針
- 王族行事の調整
- 王族間紛争の仲裁

### 貴族院

王国貴族の合議機関。

大貴族、地方領主、宮廷貴族、軍閥貴族、法衣貴族が議席を持ち、課税、叙爵、領地紛争、軍役、貴族裁判、王都儀礼、婚姻同盟などに強い発言権を持つ。

王権に従属する機関ではあるが、国王や文官府が貴族利害を無視して政策を進めることを防ぐ重しでもある。

#### 主な権限

- 新税・臨時課税への同意
- 叙爵・爵位継承に関する審査
- 貴族領紛争の調停
- 貴族裁判への関与
- 軍役負担の調整
- 王都儀礼と席次の確認
- 高位官職への推薦

### 枢密院

国王の諮問機関。

宰相、軍務卿、宮廷長官、高位聖職者、魔術師協会代表、貴族院代表などが参加し、王国全体に関わる重要案件を審議する。法的には国王を補佐する機関だが、実際には各勢力の利害調整の場でもある。

#### 主な権限

- 重要政策の事前審議
- 戦争・講和・同盟に関する助言
- 王都非常時の対応方針
- 文官府・武官府間の調停
- 聖教会・魔術師協会間の調停

## 文官府

文官府は、王都と王国中央の行政実務を担う官僚組織である。

金、法、記録、許認可、戸籍、土地台帳、祭礼、市場、魔術登録など、日常的な統治事務の大半を扱う。

```text
文官府
├─ 宰相府
├─ 財務院
├─ 民政院
├─ 司法院
├─ 外務院
└─ 魔術行政院
```

### 宰相府

文官府の中枢。

各院の政策を調整し、国王への上奏文、勅令案、行政命令を整理する。王都官僚の人事や記録にも関与する。

#### 主な権限

- 政策調整
- 勅令案の起草
- 官僚人事の調整
- 行政記録の統括
- 各院間の調停

### 財務院

税、会計、王室財産、造幣、関税を扱う。

王都の税収、商会課税、港湾関税、王室会計、寄付基金の監査を担い、文官府の中でも商会や貴族院との接触が多い。

#### 主な権限

- 王都税の徴収
- 関税管理
- 王室会計の監査
- 造幣管理
- 寄付・基金の監査
- 軍費支出の審査

### 民政院

王都住民と都市生活を扱う。

戸籍、土地台帳、商業許認可、衛生、孤児救貧、祭礼、市場管理を担う。王都で最も市民生活に近い文官組織である。

#### 主な権限

- 戸籍管理
- 土地台帳管理
- 商業許認可
- 市場管理
- 衛生行政
- 救貧・孤児事業
- 祭礼運営

### 司法院

裁判、訴訟、刑事記録、監獄管理を担う。

王都裁判所、貴族訴訟、商事裁定、刑事記録を扱う。貴族案件では貴族院と、商会案件では財務院・民政院と連携する。

#### 主な権限

- 王都裁判の運営
- 貴族訴訟の処理
- 商事紛争の裁定
- 刑事記録の管理
- 監獄管理
- 判決記録の保管

### 外務院

諸侯、外国使節、通商条約、外交儀礼を扱う。

王都に来訪する外国使節や地方諸侯との折衝を担う。宮廷府儀礼局と連携し、席次や式典も調整する。

#### 主な権限

- 外国使節対応
- 通商条約の調整
- 諸侯連絡
- 外交儀礼
- 通訳官管理

### 魔術行政院

魔術師、魔道具、王都結界、術式事故、学院認可を扱う文官組織。

魔術師協会とは協力関係にあるが、魔術師協会の自治を完全には認めず、王都内での魔術運用を行政上管理する。

#### 主な権限

- 魔術師登録
- 魔道具認可
- 王都結界管理
- 術式事故の行政審査
- 学院・協会との連絡
- 魔術関連許認可

## 武官府

武官府は、王都防衛、王宮警備、軍務、兵站、軍需契約、憲兵、騎士身分を扱う軍事系組織である。

```text
武官府
├─ 王都守備軍
├─ 近衛軍
├─ 騎士団評議会
├─ 軍務院
├─ 魔導戦術局
└─ 憲兵司令部
```

### 王都守備軍

王都の城門、市壁、街区警備を担う常設部隊。

都市防衛と市街巡邏が主な役割で、祭礼時や騒乱時には民政院や憲兵司令部と連携する。

#### 主な権限

- 城門管理
- 市壁警備
- 市街巡邏
- 緊急出動
- 祭礼警備の補助

### 近衛軍

王族と王宮を守る精鋭部隊。

王宮近衛、王族護衛、儀仗、内廷警備を担う。宮廷府との距離が近く、武官府の中でも政治性が強い。

#### 主な権限

- 王宮警備
- 王族護衛
- 謁見時警備
- 儀仗任務
- 内廷出入りの監視

### 騎士団評議会

騎士身分と騎士団を管理する組織。

叙任、決闘監督、騎士団規律、諸侯騎士団との連絡を扱う。貴族院との関係が強い。

#### 主な権限

- 騎士叙任の審査
- 騎士団規律の管理
- 正式決闘の監督
- 諸侯騎士団との連絡
- 騎士学院との連携

### 軍務院

軍政、兵站、軍需契約、兵籍、軍法を扱う。

武官府の実務中枢であり、金獅子女学院と関係の深い軍閥・商会・補給網が集中する。

#### 主な権限

- 作戦計画の調整
- 兵站管理
- 軍需契約
- 兵籍管理
- 傷病兵管理
- 軍法審査

### 魔導戦術局

軍事目的の魔術運用を扱う部局。

戦術魔術、対魔術防御、戦場通信、魔導砲、術式解析を扱う。魔術師協会や魔術行政院と緊張関係を持ちやすい。

#### 主な権限

- 戦術魔術の運用
- 対魔術防御
- 戦場通信網の管理
- 魔導砲の管理
- 術式解析班の運用

### 憲兵司令部

軍規と都市治安の境界を扱う組織。

軍人の違法行為、軍需物資の不正、港湾・倉庫区の治安、密輸、軍閥商会の監察を担う。

#### 主な権限

- 軍規監察
- 港湾・倉庫区の取締
- 密輸捜査
- 軍需物資の監察
- 商業区での武官案件処理

## 宮廷府

宮廷府は、王宮内の儀礼、女官、侍従、王族予定、王室家政、宮廷施療を扱う。

文官府とも武官府とも異なり、王族の日常と儀礼を支える宮廷内部組織である。

```text
宮廷府
├─ 内廷局
├─ 儀礼局
├─ 王室家政局
├─ 秘書局
└─ 宮廷施療局
```

### 内廷局

王妃、王女、王族女性の身辺実務を扱う。

女官、衣装、宝飾、茶会、謁見準備を担当し、桜花学園出身者が入りやすい。

#### 主な権限

- 女官管理
- 王族女性の予定調整
- 茶会準備
- 衣装・宝飾管理
- 謁見前の儀礼調整

### 儀礼局

王都の公式儀礼を管理する。

戴冠、叙任、外交儀礼、祭礼、席次を扱う。貴族院や外務院と頻繁に調整を行う。

#### 主な権限

- 戴冠儀礼
- 叙任儀礼
- 外交儀礼
- 祭礼式次第
- 席次管理

### 王室家政局

王宮内の家政と調度を扱う。

厨房、侍従、調度、宮廷医療、消耗品管理を担当する。

#### 主な権限

- 王宮厨房管理
- 侍従管理
- 宮廷医療補助
- 王宮調度管理
- 王宮物資調達

### 秘書局

王族の文書、予定、非公開連絡を扱う。

勅書起草、王族予定管理、非公開文書保管、密使連絡を担当する。

#### 主な権限

- 勅書起草
- 王族予定管理
- 非公開文書保管
- 密使連絡
- 秘密保持

### 宮廷施療局

王族と宮廷関係者の医療・回復・浄化を扱う。

聖教会と接続しており、桜花学園出身者や聖教会系回復術師の受け皿となる。

#### 主な権限

- 王族施療
- 回復術師の管理
- 薬草・聖水管理
- 聖教会との連絡
- 宮廷内の浄化儀礼

## 聖教会

聖教会は、信仰、礼拝、回復、浄化、慈善、孤児救貧を担う宗教組織である。

王権から一定の独立性を持つが、王都では宮廷府、民政院、貴族院と深く結びついている。

```text
聖教会
├─ 大聖堂府
├─ 施療院庁
├─ 慈善庁
└─ 修道会連絡庁
```

### 大聖堂府

王都大聖堂を中心とする教会中枢。

礼拝、聖印、教会記録、教区連絡を扱う。

#### 主な権限

- 礼拝儀式
- 聖印管理
- 教会記録
- 教区連絡
- 王室儀礼への参加

### 施療院庁

回復魔法、施療院、巡回施療、薬草、聖水を扱う。

桜花学園と最も関係が深い部局である。

#### 主な権限

- 王都中央施療院の運営
- 貧民区施療所の運営
- 巡回施療班の管理
- 薬草・聖水管理
- 回復術師の配置

### 慈善庁

孤児院、救貧配給、寄付者対応、貴族夫人慈善会との連絡を扱う。

民間名士や貴族夫人との接点が多く、王都の慈善事業の実務を担う。

#### 主な権限

- 孤児院管理
- 救貧配給
- 寄付者対応
- 貴族夫人慈善会との連絡
- 慈善予算の配分

### 修道会連絡庁

修道院、教会学校、礼法教育、聖歌、写本を扱う。

女子教育との関係が深く、桜花学園の宗教的基盤を支える。

#### 主な権限

- 女子修道院との連絡
- 教会学校との連絡
- 礼法教育の監修
- 聖歌・写本管理
- 修道会人事の調整

## 魔術師協会

魔術師協会は、魔術師の自治組織であり、術式研究、魔道具工房、資格、査問、学院認定を扱う。

王国に協力するが、文官府や武官府の完全な下部組織ではない。薔薇十字女学院の後援母体として大きな影響力を持つ。

```text
魔術師協会
├─ 協会評議会
├─ 術式研究院
├─ 魔道具工房連合
├─ 協会査問局
└─ 王都連絡局
```

### 協会評議会

魔術師協会の意思決定機関。

高位魔術師、術式博士、工房代表、学院関係者が参加し、協会方針、資格制度、研究認可を決定する。

#### 主な権限

- 協会方針の決定
- 魔術師資格制度の管理
- 高等研究の認可
- 魔術師協会代表の選出
- 他機関との交渉方針

### 術式研究院

魔術理論と高等術式を研究する機関。

攻性術式、結界術式、召喚・転移理論、古代術式解析などを扱う。

#### 主な権限

- 高等術式研究
- 術式論文の審査
- 研究室の認可
- 実験記録の保管
- 薔薇十字女学院への講師派遣

### 魔道具工房連合

魔道具工房を束ねる組織。

認可工房、試作魔道具、魔力炉、封印器具を管理する。

#### 主な権限

- 工房認可
- 試作魔道具の審査
- 魔力炉管理
- 封印器具管理
- 工房間紛争の調停

### 協会査問局

魔術師の規律と危険な術式運用を監査する部局。

無許可術式、禁術審査、術式事故、資格剥奪を扱う。

#### 主な権限

- 無許可術式の調査
- 禁術審査
- 術式事故調査
- 魔術師資格剥奪審査
- 協会内規律の維持

### 王都連絡局

魔術師協会と王都行政・軍務機構をつなぐ窓口。

魔術行政院、魔導戦術局、学院、協会派遣講師との連絡を担当する。

#### 主な権限

- 魔術行政院との連絡
- 魔導戦術局との連絡
- 学院認定
- 派遣講師管理
- 協会文書の王都提出

## 三女学院との接続

```text
王都上層社会
├─ 王族・貴族・民間名士・聖教会
│  └─ 王都桜花学園
│     ├─ 宮廷府
│     ├─ 聖教会
│     ├─ 慈善庁
│     ├─ 宮廷施療局
│     └─ 民政院
│
├─ 軍閥・商会・金融・海運
│  └─ 金獅子女学院
│     ├─ 武官府
│     ├─ 軍務院
│     ├─ 兵站局
│     ├─ 軍需契約局
│     ├─ 財務院
│     └─ 商業許認可局
│
└─ 魔術師協会・魔道具工房・術式研究
   └─ 薔薇十字女学院
      ├─ 魔術師協会
      ├─ 術式研究院
      ├─ 魔道具工房連合
      ├─ 魔術行政院
      └─ 魔導戦術局
```

### 王都桜花学園

聖教会、王族、貴族、民間名士に近い女学院。

回復、浄化、保護、礼法、慈善実務、宮廷作法を重視する。卒業生は宮廷府、宮廷施療局、聖教会、慈善庁、民政院に進むことが多い。

### 金獅子女学院

軍閥、商会、金融、海運に近い女学院。

資産管理、契約、兵站、軍需、商取引、後援者網を重視する。卒業生は軍務院、財務院、商会、軍需契約局、兵站関連部局に進むことが多い。

### 薔薇十字女学院

魔術師協会、魔道具工房、術式研究に近い女学院。

魔術理論、術式解析、結界術、攻性術式、高等魔術、魔術倫理を重視する。卒業生は魔術師協会、術式研究院、魔道具工房連合、魔術行政院、魔導戦術局に進むことが多い。

## 主な対立軸

### 文官府と武官府

予算、軍需契約、王都警備権限、祭礼警備、商会許認可をめぐって対立しやすい。

### 貴族院と文官府

税制、叙爵、土地台帳、貴族裁判、民間名士の登用をめぐって対立しやすい。

### 貴族院と武官府

軍役負担、騎士叙任、軍閥貴族の影響力、軍費支出をめぐって対立しやすい。

### 聖教会と魔術師協会

回復魔法の管轄、浄化術と高等術式の境界、学院教育の主導権をめぐって対立しやすい。

### 軍閥と商会

兵站契約、補給価格、鉱山権益、海運護衛、軍用魔道具の独占をめぐって対立しやすい。

- 王都桜花学園は、聖教会と王都上層社会をつなぐ。

- 宮廷府は儀礼と王族の日常で支配する。

- 魔術師協会は術式と資格で支配する。
