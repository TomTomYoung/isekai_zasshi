# 異世界雑誌 202603号 reflow ビルド手順 v0.1

## 目的

この文書は、異世界雑誌 202603号を reflow v1.0 として固定するための作業手順である。

ここでいう reflow 版とは、端末幅・文字サイズ・読書環境に応じて本文が流れるHTML群を指す。

fixed_layout 版とは別系統である。

---

## 前提

リポジトリ直下を作業ディレクトリとする。

```text
TomTomYoung/isekai_zasshi
```

重要ファイル：

```text
202603/reflow.css
202603/目次_reflow.html
202603/*/*_reflow.html
tools/create_reflow_files.py
tools/normalize_reflow_html.py
```

互換用旧名：

```text
202603/epub.css
202603/目次_epub.html
202603/*/*_epub.html
tools/normalize_epub_html.py
```

## reflow v1.0 の作業順

```text
1. reflowファイル生成を確認する
2. 目次リンクを確認する
3. 各記事HTMLを確認する
4. CSS参照を確認する
5. 画像パスを確認する
6. 表紙を確認する
7. 奥付を確認する
8. ビューアで読む
9. 致命的な崩れだけ直す
10. reflow v1.0として固定する
```

---

## 1. reflowファイル生成を確認する

`*_reflow.html` は旧 `*_epub.html` から生成される。

生成用スクリプト：

```bash
python tools/create_reflow_files.py
```

正規化スクリプト：

```bash
python tools/normalize_reflow_html.py
```

確認対象：

```text
202603/目次_reflow.html
202603/reflow.css
202603/*/*_reflow.html
```

202603号では、`*_reflow.html` は23本である。

確認例：

```bash
find 202603 -name '*_reflow.html' -print
```

---

## 2. 目次リンクを確認する

`202603/目次_reflow.html` を開く。

確認すること：

- [ ] 23本の記事が並んでいる
- [ ] 各リンク先が `*_reflow.html` である
- [ ] リンク先HTMLが存在する
- [ ] 記事順が意図通りである
- [ ] `nav class="reflow-toc"` になっている
- [ ] `epub:type="toc"` が付いている

確認済みの基準：

```text
01 ～ 23 の *_reflow.html が存在する。
各記事は ../reflow.css を参照する。
各記事は chapter-01 ～ chapter-23 の id を持つ。
```

---

## 3. 各記事HTMLを確認する

各記事について、以下を確認する。

```text
記事番号：
記事名：
HTMLファイル：*_reflow.html
画像：あり / なし / 未確認
キャプション：あり / なし / 未確認
状態：未確認 / 要修正 / OK
```

確認すること：

- [ ] XML宣言がある
- [ ] XHTML名前空間がある
- [ ] `<title>` がある
- [ ] `../reflow.css` を参照している
- [ ] `section class="chapter"` がある
- [ ] `chapter-XX` が記事番号と一致している
- [ ] 本文が途中で切れていない
- [ ] 画像参照が壊れていない

---

## 4. CSS参照を確認する

`*_reflow.html` は `../reflow.css` を参照する。

確認例：

```bash
grep -R "epub.css" -n 202603 --include='*_reflow.html'
```

期待結果：何も出ない。

```bash
grep -R "../reflow.css" -n 202603 --include='*_reflow.html'
```

期待結果：23本分が出る。

---

## 5. 画像パスを確認する

HTML内の `<img>` を確認する。

確認すること：

- [ ] `src` のパスが実ファイルに対応している
- [ ] 拡張子が一致している
- [ ] 大文字小文字の違いがない
- [ ] キャプションが画像直後にある
- [ ] 画像が本文の理解を邪魔しない

確認例：

```bash
grep -R "<img" -n 202603 --include='*_reflow.html'
```

---

## 6. 表紙を確認する

表紙がある場合：

- [ ] 雑誌名が読める
- [ ] 号数または年月が読める
- [ ] reflow版の先頭に置ける
- [ ] 画像が巨大すぎない

表紙が未完成の場合、v1.0では仮表紙を許可する。

仮表紙の条件：

```text
異世界雑誌
202603号
```

が読めればよい。
