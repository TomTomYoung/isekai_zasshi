# 202604号 企画メモ

## 1. 号の基本方針

```text
号数: 202604
媒体名: 異世界丸見え実話
形式: 固定レイアウトEPUB / 実話誌風ビジュアル雑誌
前号: 202603
```

202604号は、202603号の「異世界の裏社会・事件・怪しい商売」路線を継続しつつ、季節性として **春・新生活・王都流入・新人冒険者・入学・就職・引っ越し・花見・税・祭り前後の混乱** を軸にする。

主題：

```text
王都の春、浮かれる連中と新生活トラブル
```

狙い：

```text
- 202603と似た裏社会誌面にしつつ、号ごとの違いを出す
- 新人・春商戦・新生活・新年度ネタで記事を作りやすくする
- 実話誌風の俗っぽさを維持する
- 事件記事、告発記事、広告風ページ、カタログ、人物録を混ぜる
```

---

## 2. 202603から引き継ぐ構成

202603号の構成は以下の型を持っていた。

```text
- 表紙
- 巻頭スクープ
- 不祥事記事
- 犯罪・告発記事
- 怪しい商売記事
- 地下・裏社会記事
- 危険商品・薬物・アーティファクト記事
- 人物・職業・店・連載風ページ
- 事件簿後半
```

202604号でもこの型は維持する。

ただし、記事内容は春号として刷新する。

## 6. 制作手順

202603を直接上書きしない。

```bash
# 新号ディレクトリを作る
# 202603を複製して202604へ変換する
# 各記事HTMLを202604内容へ差し替える
# fixed_layout.html/css はテンプレート同期で揃える
```

今後必要なスクリプト修正：

```text
- 202603 固定になっている ISSUE_DIR を 202604 に切り替え可能にする
- 出力EPUB名を 202604 用にする
- exports 以下を号別に分離するか、出力名だけ変える
```

候補：

```text
ISSUE=202604 node tools/build_fixed_layout_all.mjs
```

のように環境変数で号を指定できるようにする。
