# 異世界雑誌 202603号 EPUB v1.0 リリースノート

## 目的

この文書は、異世界雑誌 202603号 EPUB v1.0 の到達点を固定するためのリリースノートである。

v1.0 は完全版ではない。

v1.0 は、既存記事をEPUBとして最初から最後まで読める状態にした一区切り版である。

---

## v1.0 の位置づけ

```text
異世界雑誌 202603号 EPUB v1.0
＝ 表紙・目次・本文・画像・奥付を備え、最初から最後まで読める最初の固定版。
```

v1.0 の目的は、以下である。

- 既存記事を固定する
- EPUBとして読める形にする
- 目次から各記事へ移動できるようにする
- 画像・キャプションを最低限破綻しない状態にする
- 表紙と奥付を入れる
- 以後のv1.1、v2.0、次号制作の基準点にする
