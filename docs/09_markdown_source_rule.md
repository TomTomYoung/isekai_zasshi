# Markdown source rule

記事本文の正本は `.md` とする。

HTMLは正本ではない。HTMLは `.md` から作る派生物とする。

各記事ディレクトリの基本構成：

- `企画.md`: 記事設計
- `記事名.md`: 本文正本
- `記事名.html`: 中間HTML
- `fixed_layout.html`: 固定レイアウト用HTML
- `fixed_layout.css`: 固定レイアウト用CSS

本文を書く場合は、必ず `記事名.md` を作る。

本文を直す場合も、必ず `記事名.md` を直す。

HTMLだけを更新して本文更新とみなしてはいけない。
