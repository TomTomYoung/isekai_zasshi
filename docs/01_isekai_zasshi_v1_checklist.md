# 異世界雑誌 202603号 reflow v1.0 チェックリスト

## 目的

異世界雑誌 202603号を、reflow版として読める完成物にする。

このv1.0では、新規記事を増やすことを目的としない。

目的は、既存記事・既存HTML・既存CSS・既存画像・既存TOCを整理し、最初から最後まで読めるreflow版として一区切りをつけることである。

fixed_layout版は別系統で扱う。

---

## v1.0 の完成条件

以下を満たしたら、reflow v1.0 とする。

- [ ] 最初から最後まで読める
- [ ] 表紙がある
- [ ] 目次がある
- [ ] 目次から全記事に移動できる
- [ ] 全記事にタイトルがある
- [ ] 全記事の本文が途中で壊れていない
- [ ] 画像が画面から極端にはみ出さない
- [ ] キャプションが画像と大きく分離しない
- [ ] XHTMLとして致命的に壊れていない
- [ ] 奥付がある
- [ ] reflow v1.0としてGitHub上で固定できる

---

## v1.0 でやらないこと

以下は、reflow v1.0ではやらない。

- [ ] 新記事を増やさない
- [ ] 世界設定を増やさない
- [ ] 神話や歴史を増やさない
- [ ] CSSを根本設計から作り直さない
- [ ] EPUB仕様を過剰研究しない
- [ ] KDP完全最適化を目指さない
- [ ] fixed_layout版との完全一致を目指さない
- [ ] 全端末で完璧な表示を目指さない
- [ ] 画像生成を増やして収拾不能にしない

v1.0 は、完全版ではなく、一区切り版である。
