# 202604号 ボリューム増補仕様

この文書は、`異世界丸見え実話 202604` を3月号と同程度のボリューム・内容密度へ引き上げるための制作仕様である。

現状の `202604/` 配下の記事HTMLは、制作開始用の雛形であり、そのままでは3月号と比べて本文量・誌面密度・企画数が不足している。

---

## 1. 基本方針

202604号の主題は以下とする。

```text
王都の春、浮かれる連中と新生活トラブル
```

3月号で成立していた強み：

```text
- 巻頭スクープの強い俗っぽさ
- 不祥事、告発、裏商売、事件簿の連続
- 名鑑、カタログ、店紹介、連載風ページによる誌面変化
- 後半に事件簿を集中させる構成
- 各記事が単なる説明でなく、目撃証言、関係者談、本誌の見立てを持つ
- 固定レイアウトで読ませるだけの分量がある
```

202604号で意識すること：

```text
- 春、新生活、新人、王都流入、祭り、花見、下宿、登録、講習会を軸にする
- ただの案内記事で終わらせず、必ず俗っぽい利害・失敗・噂を入れる
- 1記事につき最低3〜5セクションを持たせる
- 可能なら各記事に表、囲み、リスト、証言、ランキング、チェックリストのどれかを入れる
- 画像がない記事でも、誌面上の見せ場になる見出し・表・囲みを入れる
```

---

## 2. 目標ボリューム

3月号と同程度にするため、202604号は以下を目標にする。

```text
記事数: 00〜23 の24項目維持
各本文記事: 1200〜2200字程度
カタログ・名鑑記事: 900〜1600字 + 表/リスト
巻頭記事: 2200〜3200字程度
後半事件簿: 1600〜2600字程度
固定レイアウト出力: 3月号と同等のページ密度を目指す
```

現在の雛形記事は多くが `500〜900字程度` なので、各記事をおおむね2〜3倍へ増補する。

---

## 3. 全記事共通の増補テンプレート

各記事は、原則として以下の構成を持つ。

```text
1. リード
2. 事件・話題の概要
3. 現場描写
4. 関係者証言
5. 手口・構造・背景
6. 表・リスト・チェック欄
7. 本誌の見立て
8. 余韻または皮肉の締め
```

最低限必要な要素：

```text
- h1: 記事タイトル
- lead: 80〜160字
- h2: 3〜5個
- p: 8〜16段落
- blockquote: 1個以上
- ul/table/note-box のいずれか1個以上
```

使う語り口：

```text
- 断定しすぎず、実話誌風に「本誌が聞き込みを行った」「関係者によれば」「噂は食い違う」と書く
- 実在事件のように見せすぎない
- 現実の犯罪指南にならないよう、手順や実行方法は具体化しすぎない
- 俗っぽくするが、KDP登録に支障が出る直截表現は避ける
```

```text
- 見出しだけのページ
- 画像だけのページ
- 本文数段落だけの空いたページ
- カタログ記事なのに表や商品枠がないページ
- 事件簿なのに証言や時系列がないページ
```

理想：

```text
画像入りページ: 見出し + 画像 + 本文2〜4段落
本文ページ: h2 + 本文5〜8段落 + 証言/囲み
カタログページ: h2 + 商品表 + 短評
名鑑ページ: カード型リスト + 本誌コメント
```

## 10. 結論

202604号は、現状の雛形のままでは3月号に比べて明らかに薄い。

3月号並みにするには、単に記事数を揃えるだけでは足りない。各記事に以下が必要である。

```text
- 具体的な現場描写
- 複数の証言
- 表やリスト
- 本誌の見立て
- 誌面上の視覚的な塊
- 春号らしい季節性
```

202604号の核は、

```text
春の王都に集まる新人・客・商人・祭り・新生活を、実話誌風に俗っぽく切る
```

ことである。
