## 制作方式

202603号 fixed_layout版は、以下の方式で制作した。

```text
1. 各記事フォルダに fixed_layout.html / fixed_layout.css を置く
2. Playwrightで 1456×2056px のページPNGを書き出す
3. 記事名付きPNGをKindle用連番PNGへ変換する
4. 連番PNGを固定レイアウトEPUB/KPF化する
5. KDPへ投入する
```

正規の号数別出力系統：

```text
exports/202603/fixed_layout_images/
exports/202603/kindle_pages/
exports/202603/isekai_marumie_jitsuwa_202603_fixed_layout.epub
```

ビルド導線：

```bash
npm run build:fixed-layout-epub
```

分割実行する場合：

```bash
npm run export:fixed-layout
npm run prepare:kindle-pages
npm run build:epub
```

## 詰まった点

```text
・表紙を最初から制作対象に入れていなかった
・3カラム記事は可読性が落ちやすかった
・本文量が少ない記事に2カラムを当てると紙面が空いた
・表、名鑑、広告は通常本文レイアウトと相性が悪かった
・画像を後から足すと紙面バランスが崩れやすかった
・Kindle Create / KDP投入用のページ順確認が後工程に寄った
```

---

## 次号へ持ち越す制作ルール

202604号以降では、以下を初期ルールとする。

```text
・0001ページは必ず表紙
・表紙は本文完成後ではなく、初期構成に含める
・通常記事は2カラム基準
・3カラムは原則禁止
・本文量が少ない記事は1カラム
・表を含む記事は専用レイアウト
・人物名鑑は専用カード型レイアウト
・広告記事は広告として別レイアウトを切る
・画像主役の記事は最初から画像枠を確保する
・Kindle用連番PNGは早期に出して順番を確認する
```
