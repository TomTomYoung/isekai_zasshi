# 異世界雑誌 202603号 reflow v1.0 リリースノート

## 目的

この文書は、異世界雑誌 202603号 reflow v1.0 の到達点を固定するためのリリースノートである。

reflow版は、端末幅・文字サイズ・読書環境に応じて本文が流れる版である。

fixed_layout版は、固定紙面をPNG化する別系統である。

---

## v1.0 の位置づけ

```text
異世界雑誌 202603号 reflow v1.0
＝ 目次・本文・画像・奥付を備え、最初から最後まで読める最初のreflow固定版。
```

## リリース判定

以下を満たせば、reflow v1.0 としてリリースしてよい。

```text
reflow版が開く。
表紙、目次、本文、画像、奥付がある。
目次から23本すべての記事に移動できる。
本文が最初から最後まで読める。
致命的な画像切れ・リンク切れ・本文崩壊がない。
```
