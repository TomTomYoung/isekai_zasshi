## 目的

この文書は、異世界雑誌 202603号を EPUB v1.0 として固定するための作業手順である。

目的は、EPUB仕様を研究し続けることではない。

## 前提

リポジトリ直下を作業ディレクトリとする。



## 2. ファイル構成を確認する

最低限、以下を確認する。

```text
202603/
  epub.css
  目次_epub.html
  */*_epub.html
```

確認コマンド例：

```bash
find 202603 -name '*_epub.html' -print
find 202603 -name '*.css' -print
find 202603 -type f \( -name '*.png' -o -name '*.jpg' -o -name '*.jpeg' -o -name '*.webp' \) -print
```

確認すること：

- [ ] EPUB用HTMLが存在する
- [ ] `202603/目次_epub.html` が存在する
- [ ] `202603/epub.css` が存在する
- [ ] HTMLから参照される画像が存在する
- [ ] ファイル名の表記揺れがない

---

## 3. HTMLを正規化する

以下を実行する。

```bash
python tools/normalize_epub_html.py
```

期待される出力：

```text
Normalized files:
- ...
```

または、すでに正規化済みなら、

```text
No changes needed.
```

このスクリプトが行う主な処理：

- XML宣言の追加
- XHTML名前空間の追加
- 目次navへの `epub:type="toc"` 付与
- `<meta>`、`<link>`、`<hr>`、`<br>`、`<img>` のXHTML風正規化
- 番号付き記事の chapter id 正規化

確認すること：

- [ ] 実行時エラーがない
- [ ] 対象HTMLが更新される、または `No changes needed.` になる
- [ ] Git diffで意図しない大破壊が起きていない

確認コマンド例：

```bash
git diff -- 202603
```
